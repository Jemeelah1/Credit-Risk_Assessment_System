An end-to-end Machine Learning web application designed to evaluate loan applicants' creditworthiness and support data-driven decision-making in digital banking environments.

## 🚀 Live Demo
Access the deployed application here: [Credit Risk Assessment System](https://credit-risk-assessments-system.streamlit.app/)

## Key Features
* **Interactive Assessment:** Computes real-time default probability scores and approval recommendations based on borrower demographic and financial profiles.
* **Machine Learning Pipeline:** Implements data scaling, one-hot encoding, and binary classification via Scikit-Learn models.
* **Audit & History Log:** Integrates with an SQLite database to persist assessment records for post-analysis and record-keeping.
* **Custom UI/UX:** Styled using Streamlit and CSS with smooth visual indicators and interactive form inputs.

## Tech Stack
* **Language:** Python 3.x
* **User Interface:** Streamlit, Custom HTML/CSS
* **Machine Learning & Data Processing:** Scikit-Learn, Pandas, Joblib
* **Database:** SQLite3
